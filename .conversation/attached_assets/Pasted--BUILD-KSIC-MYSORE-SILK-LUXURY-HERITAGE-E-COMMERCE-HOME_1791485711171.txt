# BUILD: KSIC MYSORE SILK — LUXURY HERITAGE E-COMMERCE HOMEPAGE

Build a complete production-quality **Next.js App Router + TypeScript** marketing/e-commerce homepage for **KSIC Mysore Silk**.

The website must feel like a **global luxury fashion house** — inspired by the visual restraint, editorial art direction and premium digital experience of brands such as **Gucci, Prada, Dior, Bottega Veneta and Hermès**.

Do NOT make this look like:
- a generic Indian saree website
- a generic Shopify template
- a dashboard
- a SaaS landing page
- a card-heavy e-commerce grid
- a crowded government website
- a template with excessive rounded cards
- a purple/gold "traditional Indian" website

The design should communicate:

**ROYAL · EDITORIAL · QUIET LUXURY · MYSORE HERITAGE · CRAFTSMANSHIP · MODERN INDIA**

The website should feel expensive before the user reads a single word.

# 3. CORE ART DIRECTION

This is the most important requirement.

Think like a luxury fashion art director rather than a UI designer.

The website should use:

- enormous typography
- dramatic image crops
- generous whitespace
- asymmetrical compositions
- editorial layouts
- thin borders
- restrained animation
- subtle maroon/gold details
- large photographic surfaces
- overlapping typography
- sophisticated negative space
- elegant image masking
- carefully controlled hierarchy

Avoid:

- excessive shadows
- excessive gradients
- excessive border-radius
- glassmorphism
- floating dashboard cards
- emoji
- giant icon boxes
- unnecessary badges
- excessive gold
- excessive decorative patterns
- cheap-looking animations
- excessive text
- multiple CTAs fighting for attention

Luxury principle:

**Less UI. More atmosphere.**

Every section should have a clear visual idea.

# 21. MOTION SYSTEM

Create:

```text
src/hooks/useKsicMotion.ts
```

Implement:

### Scroll reveal

Elements with:

```html
class="rv"
```

should reveal using IntersectionObserver.

Initial:

```css
opacity: 0;
transform: translateY(30px);
```

Visible:

```css
opacity: 1;
transform: translateY(0);
```

Use elegant easing.

---

### Stagger

Support:

```html
data-stagger="100"
```

for child delays.

---

### Header scroll state

After:

```text
24px
```

header receives:

```text
scrolled
```

class.

---

### Parallax

Support:

```html
data-parallax
```

for:

- craft image
- occasion image
- potentially heritage image

Use subtle movement only.

Never overdo the parallax.

# 31. FINAL QUALITY BAR

Before finishing, inspect the page as a creative director.

Ask:

### Does this look like a luxury fashion house?

If no → redesign.

### Does Mysore Silk feel more important than KSIC?

Yes. KSIC is the institution, but **Mysore Silk is the hero brand experience.**

### Does the first viewport immediately communicate luxury?

Yes.

### Does the page breathe?

Yes.

### Are there too many cards?

If yes → remove them.

### Are there too many buttons?

If yes → remove them.

### Is there too much gold?

If yes → reduce it.

### Does it feel like an Indian government website?

Absolutely not.

### Does it feel like a generic Shopify store?

Absolutely not.

### Does it feel like Prada / Gucci / Dior-level editorial web design adapted to Mysore Silk?

That is the target.
